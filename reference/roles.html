Справочник

Роли и доступы

Четыре роли в системе с разными уровнями доступа. Каждая роль видит только те разделы, которые нужны для её работы.

👤
Роли в системе
Сотрудник Врач-оптометрист, консультант EMPLOYEE
Базовая роль. Как правило, сотрудники не работают с системой напрямую — носят бейджи и взаимодействуют с клиентами. Доступ к основным разделам аналитики есть, но используется редко.
Главная страница Динамика продаж Результаты сотрудников Карта врача / консультанта Анализ филиала Аудиобейджи План задач на неделю
РОП Руководитель отдела продаж SALES_HEAD
Основной пользователь системы. Работает с аналитикой ежедневно: разбирает результаты филиалов, смотрит карты сотрудников, ставит задачи, контролирует бейджи. Дополнительно видит активность и управляет пользователями.
Все разделы сотрудника + Активность + Пользователи
КД Коммерческий директор COMMERCIAL_DIRECTOR
Стратегический уровень. Видит всё, что видит РОП, плюс разделы для управления мотивацией и еженедельного контроля РОПов через Планёрку КД.
Все разделы РОПа + Мотивация + Планёрка КД
Администратор Администратор системы ADMINISTRATOR / ROOT
Полный доступ ко всем разделам без ограничений. Управляет справочниками, настройками и учётными записями пользователей.
Все разделы системы + Настройки + Управление справочниками
