Планёрка КД

Еженедельный AI-дайджест для коммерческого директора. Система сама собирает данные по всем РОПам, оценивает результаты задач прошлой недели и формирует повестку для управленческого разбора. Не нужно смотреть несколько разделов — вся картина на одном экране.

🎯
Зачем нужна планёрка
Готовая повестка — AI компилирует данные по всем РОПам и их филиалам в единый структурированный план. Не надо собирать цифры вручную.
Контроль задач — видно, какие задачи из прошлой недели дали результат, а какие нет. Это фактическая основа для разговора с каждым РОПом.
Кто без задач — система сама указывает сотрудников, на которых в календаре нет задач на эту неделю, с объяснением причины.
Структура на встречу — план идёт по РОПам, внутри каждого — по блокам. Можно вести планёрку прямо по этому экрану.

Что внутри каждой карточки РОПа
Анализ филиалов — по каждому салону: % выполнения плана, зона (зелёная / жёлтая / красная) и AI-объяснение — что именно происходит и почему.
Результаты задач — прошлая неделя — что РОП делал с каждым сотрудником, и дало ли это результат. Четыре статуса: ↑ Растёт, ↓ Падает, → Без изменений, ∅ Нет данных. Рядом с каждой задачей — спарклайн: мини-график динамики показателя за 5 последних недель с подсказкой при наведении.
Задачи на эту неделю — что уже стоит в календаре у РОПа. Для каждого сотрудника: задача, описание и время в расписании (например, «Пн 10:00»).
Без задачи — требуют внимания — сотрудники, на которых задач нет, с AI-объяснением почему это проблема. Это повестка для разговора с РОПом прямо сейчас.
Итоговая строка — три цифры: задач выполнено / дали результат / сотрудников охвачено. Быстрая оценка качества работы РОПа за неделю.

История задач по сотруднику

В блоке «Результаты задач» у каждой задачи есть кнопка «Показать историю». Она раскрывает помесячную разбивку: сколько задач ставилось по этому сотруднику и каков был результат. AI добавляет короткий комментарий — объясняет, почему динамика именно такая.

ℹ️ История помогает понять, не разовая ли это просадка или системная проблема, которую уже несколько недель не удаётся закрыть.
▶️
Как использовать на планёрке
1
Перед встречей — сгенерируй план
Открой страницу, выбери прошедшую неделю, нажми «Сгенерировать план». Это займёт несколько секунд. Лучше делать с утра в день планёрки.
2
Начни с итоговой строки каждого РОПа
% плана и прогноз выручки видны прямо в шапке карточки. Это даёт первичную расстановку приоритетов — кому уделить больше времени.
3
Разбери красные и жёлтые филиалы
В блоке «Анализ филиалов» AI объясняет причину просадки. Это основа для разговора: что конкретно происходит и почему.
4
Проверь результаты задач прошлой недели
Задачи со статусом ↓ или «Без изменений» — повод для прямого вопроса РОПу: что пошло не так и что будет делать иначе.
5
Разбери блок «Без задачи»
Каждый сотрудник без задачи — это пробел в управленческой работе РОПа. Зафиксируй, кому нужно поставить задачу до конца дня.
6
Проверь задачи на эту неделю
Убедись, что у каждого проблемного сотрудника есть конкретная задача с временем в календаре — не просто намерение, а зафиксированное действие.
✅ Хорошая планёрка КД длится 30–45 минут и заканчивается тем, что у каждого РОПа есть конкретные задачи на неделю с датами и ответственными.
