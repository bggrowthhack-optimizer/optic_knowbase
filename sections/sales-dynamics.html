Раздел системы

Динамика продаж

Инструмент точечного анализа: строишь график по любому показателю за нужный период и видишь, где началась просадка или как сработало изменение в работе сотрудника.

🎯
Когда использовать
Найти причину просадки — показатель упал, нужно понять с какой даты и насколько резко
Проверить результат работы с сотрудником — видно ли улучшение после разбора или поставленной задачи
Сравнить с прошлым годом — тот же период год назад, чтобы учесть сезонность
Сверить данные — уточнить конкретное значение за неделю или день
🗂

Параметры фильтра
Показатель
Любая метрика из справочника
Период
Произвольный диапазон дат
Группировка
Без группировки / Дни / Недели / Месяцы / Кварталы
Сотрудник
Врач или консультант (опционально)
Год к году
Чекбокс — показывает данные того же периода прошлого года рядом на графике

После выбора параметров нажать «Применить». Кнопка неактивна, если фильтры не изменились.

📅
Как выбрать группировку
Без группировки
Каждая точка данных отдельно — для очень детального разбора.
По дням
Когда нужно найти точечную ошибку: конкретную дату, день без записей, сравнить дни работы сотрудника.
По неделям Основной
Рабочий вариант по умолчанию. Сглаживает случайные колебания, показывает устойчивую тенденцию.
По месяцам
Для долгосрочной динамики и сезонных сравнений — например, апрель этого года vs апрель прошлого.
По кварталам
Для стратегического обзора за полгода–год. Используется редко.
📆
Год к году
При включённом чекбоксе на графике появляются два столбца на каждый период — синий (текущий год) и оранжевый (прошлый год). В тултипе видна дельта в процентах. Используй, чтобы отделить реальный рост от сезонного.
📊
Карточки метрик под графиком

Под главным графиком — сетка карточек по всем включённым метрикам. Каждая карточка показывает:

Ср. чек заказа
14 320 ₽
↗ Рост

Кликни на столбец в мини-графике — карточка покажет значение за выбранную неделю

Тренд — Рост / Снижение / Стабильно (или % к прошлому году при включённом «год к году»)
Мини-график — недельные столбцы за период. Кликни на любой — увидишь значение за ту неделю
Кнопка «Детализация» — появляется для отдельных метрик (подборы, ВТЛ, конверсии). Открывает разбивку по типам с числами и процентами
🎛
Настройка отображаемых метрик

Кнопка «Настроить метрики» под карточками открывает список всех доступных показателей. Включай только те, которые нужны тебе для анализа — настройки сохраняются в системе. Доступны все 34 метрики, сгруппированные по категориям: воронка, конверсии, средние чеки, ВТЛ, итоговые.

Главный принцип
Заходи с конкретной гипотезой, не «просто посмотреть». Если не знаешь что ищешь — сначала открой Анализ филиала, найди проблему там, и только потом приходи сюда за деталями.
