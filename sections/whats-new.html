AI-инструменты
v1.38
Разбор записи встречи 1:1
В задаче «Развитие» появилась загрузка аудиозаписи встречи с сотрудником — система расшифровывает её и предлагает черновик результата с пометкой «из записи». Под результатом — «Комментарий помощника»: что получилось, что не сработало, что попробовать в следующий раз. Все разобранные встречи собираются в подразделе «Встречи 1:1 РОП».

v1.38
Встречи 1:1 РОП Новый подраздел
Архив всех разобранных записей встреч: дата, РОП, сотрудник, показатель, расшифровка, результат и комментарий помощника. Фильтры по сотруднику, руководителю и дате. РОП видит свои встречи, коммерческий директор — все.

v1.34
Протоколы планёрок Новый раздел
Появился раздел «Протоколы встреч»: загружаешь аудиозапись планёрки — система расшифровывает её и формирует структурированный отчёт. Отчёт можно отредактировать и подтвердить. Пока идёт обработка — в списке виден статус «В обработке», страница обновляется сама.

Задачи и планирование
v1.35
Регулярные задачи
В форме появился переключатель «Регулярная задача»: при включении выбираешь периодичность (ежедневно, еженедельно, ежемесячно) — система автоматически создаёт повторяющиеся задачи на горизонт 30 дней.
Задачи →
v1.35
Обновлённая форма постановки задачи
Тип задачи выбирается переключателем в верхней части формы: «Развитие» или «Организационные». Для организационных задач поля «Сотрудник» и «Показатель» скрываются автоматически. Завершить организационную задачу можно без заполнения результата.
Задачи →
v1.32
Личный отчёт для РОПа
У РОПа появилась кнопка «Мой отчёт за неделю» — только его часть отчёта: своя строка дисциплины, свой фокус по метрикам, своя оценка качества разбора. Данные других РОПов недоступны. У коммерческого директора и администраторов отчёт остался полным.
Задачи →
v1.31
Два типа задач: Развитие и Организационные
При постановке задачи выбирается категория. В отчёте за неделю организационные задачи вынесены в отдельный блок — фокус по метрикам и качество разбора считаются только по задачам «Развитие».
Задачи →
v1.27
День формирования отчёта за неделю
Администратор может выбрать день недели, в который формируется автоматический отчёт. Если выбрать более поздний день (например, среду), у руководителей будет время дозаполнить результаты прошлой недели до «заморозки» отчёта.
Задачи →
v1.21
Кнопки закрытия: Завершить, Отложить, Отменить
Вместо одной кнопки — три с подсказками: «Завершить» закрывает как успешную, «Отложить» оставляет задачу в списке незакрытых с пометкой, «Отменить» закрывает как невыполненную. Отложенные задачи больше не пропадают из вида.
Задачи →
v1.18
РОП может быть исполнителем задачи
В поле «Сотрудник» теперь можно выбрать РОПа — в том числе себя. Удобно для задач на собственное развитие. Когда задачу создаёт РОП, исполнителем по умолчанию подставляется он сам.

Сотрудники и пользователи
v1.30
Управление справочником сотрудников Новая вкладка
В разделе «Пользователи» появилась вкладка «Сотрудники» (для администраторов): таблица ФИО, роли и статуса. Можно добавить сотрудника вручную, отредактировать данные или деактивировать уволенного — история его заказов и приёмов при этом сохраняется.
v1.26
Конверсия рецепт → заказ теперь и у консультантов
В таблице консультантов появился столбец «% рецепт → заказ (наш)» — доля заказов по своим рецептам от рецептов, выписанных на приёмах с участием консультанта. Раньше этот столбец показывал 0, теперь заполняется по реальным данным.
Сотрудники →
v1.20
РОПы могут корректировать баллы речевой аналитики
В карточке врача РОП теперь может изменить балл блока чек-листа или навыка, указав причину. У консультанта баллы корректируются внутри конкретного взаимодействия. Все изменения видны в «Истории изменений».

Аудиобейджи
v1.36
Исключение взаимодействия из расчёта метрик
У каждого взаимодействия консультанта появилась кнопка «Исключить из расчёта метрик» — открывает окно с полем причины. После исключения пересчитываются балл, число диалогов, соблюдение стандартов и навыки продаж. Исключённое взаимодействие остаётся в списке (помечается серым), его всегда можно вернуть обратно.

Поддержка формата MP3
При загрузке записи с бейджа теперь можно выбрать файл в формате MP3 — не только WAV. Конвертировать MP3 в WAV перед загрузкой больше не нужно. Проверки длительности и имени файла работают для обоих форматов одинаково.

Складская аналитика
v1.33
Выгрузка и печать выбранных перемещений
В журнале у каждой строки появилась галочка. Отметь нужные перемещения — выгрузка и печать будут только по ним. Если ничего не отмечено — работают по всему списку, как раньше.
Склад →
v1.29
Вкладки «Активные» и «Завершённые» в журнале
Журнал перемещений разделён на две вкладки — активные перемещения (подтверждено, в пути) и завершённые (выполнено). Выполненные больше не смешиваются с текущими. Печать и выгрузка формируются по текущей вкладке.
Склад →
v1.25
Динамические рекомендации по перемещениям
Рекомендации учитывают уже подтверждённые перемещения: отправленный сток больше не предлагается повторно. Если дефицит частично закрыт — рекомендация показывает только остаток. Счётчики пересчитываются сразу после подтверждения.
Склад →
v1.24
Выгрузка в Excel, печать и комментарии к перемещениям
Журнал перемещений можно выгрузить в Excel и распечатать с учётом выбранных фильтров. К каждому перемещению можно добавить произвольный комментарий — отображается в распечатке и в выгрузке.
Склад →
v1.19
Детализация состава перемещения
При создании перемещения теперь виден его состав: модель, материал, размер, количество в наличии. По каждой позиции можно задать, сколько единиц перемещать, — внизу показывается итог.
Склад →
v1.14
Раздел «Складские остатки» Новый раздел
Появился раздел «Складская аналитика»: KPI по сети, разбивка по филиалам и категориям, рекомендации по перемещениям и журнал ротаций. Сток обновляется из выгрузки раз в неделю.
