Раскрытый филиал — пять блоков

Клик на строку раскрывает таблицу с показателями. Блоки идут сверху вниз — читай в том же порядке.

Блок 1
Воронка продаж
Количественные показатели воронки: сколько было окон, подборов, рецептов и заказов (наших) за выбранный месяц. По каждому — факт, план и % выполнения.
Блок 2
Показатели эффективности воронки
Конверсии между шагами воронки: % загрузки окон, % подбор→рецепт, % рецепт→заказ, % подбор→заказ. Показывают, насколько эффективно клиент проходит каждый этап.
Блок 3
Анализ ВТЛ
Показатели по высокотехнологичным линзам: % рекомендаций, % продаж, количество рекомендаций, количество заказов и средний чек заказа ВТЛ.
Блок 4
Анализ Наши / Чужие
Структура заказов по типу рецепта: заказы по нашему рецепту и по стороннему. По каждому типу — количество заказов, сумма и средний чек.
Блок 5
Итого по всем заказам
Совокупные итоги по всем заказам без разбивки по типу рецепта: общее количество, сумма и средний чек.

Факт из плана — сколько есть сейчас из запланированного на месяц.   % — выполнение плана: красный / жёлтый / зелёный.   Динамика — растёт или падает к прошлой неделе.   ▼ — клик раскрывает динамику по неделям.

ℹ️ Кнопка «Детализация» есть у некоторых метрик — открывает разбивку внутри показателя по типам. Например, у «Подборов» — какие типы подборов были, у «Рекомендаций ВТЛ» — какие типы линз рекомендовались.
