Цветная полоса и бейдж слева — зона (зелёная / жёлтая / красная). Справа — ср. чек и выручка. Кнопка «Анализ филиала» открывает AI-разбор: зона, топ-3 проблемы, лучшие и худшие сотрудники. Клик на строку — раскрывает детальные блоки.

Раскрытый филиал — пять блоков

Клик на строку раскрывает таблицу с показателями. Блоки идут сверху вниз — читай в том же порядке.

Блок 1
Воронка продаж
Окна → Подборы → Рецепты → Заказы (наши). Факт из плана — здесь видно, где обрыв воронки
Блок 2
Показатели эффективности воронки
% загрузки, % подбор→рецепт, % рецепт→заказ, % подбор→заказ. Помогает понять, на каком шаге теряем клиентов
Блок 3
Анализ ВТЛ
% рекомендаций, % продаж, кол-во заказов, ср. чек ВТЛ. ВТЛ — главный рычаг среднего чека
Блок 4
Анализ Наши / Чужие
Структура заказов по типу рецепта: наши заказы vs чужие, чеки по каждому типу
Блок 5
Итого по всем заказам
Итоговое кол-во заказов, сумма и ср. чек с учётом всех типов

Факт из плана — сколько есть сейчас из запланированного на месяц.   % — выполнение: красный / жёлтый / зелёный.   Динамика — растёт или падает по сравнению с прошлой неделей.   ▼ — клик раскрывает недельную динамику.

ℹ️ Кнопка «Детализация» есть у некоторых метрик (Подборы, % подбор→рецепт, % подбор→заказ, Рекомендации ВТЛ) — открывает разбивку внутри показателя по сотрудникам.
