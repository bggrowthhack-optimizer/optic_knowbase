Что такое Optimizer

Optimizer — аналитическая платформа для управления сетью оптик. Она собирает данные о продажах, сотрудниках и взаимодействиях с клиентами и превращает их в понятные отчёты и рекомендации.

Система строится вокруг воронки продаж оптики: окна → подборы → рецепты → заказы. На каждом шаге видно, где теряются клиенты и что с этим делать.

Ключевая особенность — речевая аналитика: бейджи записывают взаимодействия с клиентами, система расшифровывает и оценивает их, РОП видит конкретные пробелы и может давать обратную связь напрямую из системы.

👤
Кто работает в системе
Сотрудник
Врач, консультант
Видит базовые разделы. Обычно не работает с системой напрямую — носит бейдж и взаимодействует с клиентами.
РОП
Руководитель отдела продаж
Основной пользователь. Анализирует результаты филиалов, смотрит карты сотрудников, ставит задачи, работает с бейджами. Плюс доступ к разделам «Активность» и «Пользователи».
КД
Коммерческий директор
Видит всё, что видит РОП, плюс разделы «Мотивация» и «Планёрка КД». Работает со стратегическими показателями и контролирует РОПов.
Администратор
Администратор / ROOT
Полный доступ ко всем разделам. Управляет справочниками, пользователями и настройками системы.

С чего начать — для РОПа
1
Открой главную страницу
Фиолетовый блок вверху — прогресс месяца. Смотришь сразу: сколько % месяца прошло и сколько % плана выполнено. Если разрыв большой — переходишь к деталям.
2
Зайди в «Результаты по филиалам»
Раскрой каждый филиал — видишь воронку, конверсии, ВТЛ. Красные показатели — точки для работы.
3
Открой «Анализ филиала» для проблемного салона
Здесь система сама показывает ТОП-3 показателей, которые мешают плану, и предлагает конкретные действия. Ставь задачи прямо из блока.
4
Зайди в карту конкретного сотрудника
«Карта врача» или «Карта консультанта» — видишь показатели, динамику, блоки речевой аналитики и каждый приём с резюме. Там же ставишь задачу конкретному человеку.
5
Контролируй задачи в «Плане задач на неделю»
Все задачи, поставленные из анализа и карт сотрудников, попадают сюда. Отмечай выполненные, добавляй результаты, смотри незакрытые.
6
Организуй работу с бейджами
Без загруженных записей карты сотрудников будут пустыми. Убедись, что администратор выдаёт, регистрирует и загружает записи каждый день.
Главный цикл работы: Анализ → Задача → Проверка результата → Следующий анализ. Всё остальное — инструменты для этого цикла.

Типичный рабочий день РОПа в системе

Система не требует часами сидеть в отчётах. Стандартный ежедневный маршрут занимает 20–30 минут.

Утро
Главная → Фиолетовый блок → Красные карточки → Результаты по филиалам
Работа с проблемой
Анализ филиала → ТОП-3 проблем → Карта сотрудника → + Задача
Контроль
План задач на неделю → Отметить выполненные → Незакрытые задачи
